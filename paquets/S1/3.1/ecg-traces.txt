# IADE – ECG

//= [img:images/ecg-05.jpg] Bande de rythme : quel est le diagnostic ?
[img:images/ecg-05.jpg] Quel est le diagnostic sur cette bande de rythme ? :: BAV du 2e degré Mobitz I (Wenckebach)\nLe PR s'allonge d'un battement à l'autre\nPuis une P n'est pas suivie de QRS\nLe cycle repart avec un PR plus court\nMobitz II : PR constant avant la P bloquée (plus grave)\nSource : LITFL ECG Library (CC BY-NC-SA 4.0)
//= [img:images/ecg-02.jpg] ECG 12 dérivations : quel est le diagnostic ?
[img:images/ecg-02.jpg] Quel est le diagnostic sur cet ECG 12 dérivations ? :: Bloc auriculo-ventriculaire du 1er degré (BAV 1)\nChaque P est suivie d'un QRS\nPR allongé (> 200 ms, ici ≈ 260 ms) et constant\nAucune P bloquée → pas un BAV 2\nSource : LITFL ECG Library (CC BY-NC-SA 4.0)
//= [img:images/ecg-08.jpg] ECG 12 dérivations : quel est le diagnostic ?
[img:images/ecg-08.jpg] Quel est le diagnostic sur cet ECG 12 dérivations ? :: BAV du 3e degré (BAV complet)\nLes P ont leur propre rythme, plus rapide que les QRS\nPas de relation fixe entre P et QRS (PR apparents variables)\nQRS d'échappement lents\nAu bloc : risque de bradycardie sévère → isoprénaline, entraînement électrosystolique\nSource : LITFL ECG Library (CC BY-NC-SA 4.0)
//= [img:images/ecg-06.jpg] Bande de rythme : quel est le diagnostic ?
[img:images/ecg-06.jpg] Quel est le diagnostic sur cette bande de rythme ? :: Extrasystoles ventriculaires en bigéminisme\nUn QRS fin normal alterne avec un complexe large de forme différente\nLe complexe large arrive trop tôt, sans P devant, suivi d'une pause\nPrématuré → extrasystole ; tardif → ce serait un échappement\nSource : LITFL ECG Library (CC BY-NC-SA 4.0)
//= [img:images/ecg-01.jpg] ECG 12 dérivations : quel est le diagnostic ?
[img:images/ecg-01.jpg] Quel est le diagnostic sur cet ECG 12 dérivations ? :: Fibrillation atriale (FA) à réponse ventriculaire rapide\nIntervalles R-R irréguliers, sans motif répétitif\nQRS fins\nPas d'onde P identique avant chaque QRS\nÀ distinguer : tachycardie sinusale (P avant chaque QRS), flutter (activité atriale régulière en dents de scie)\nSource : LITFL ECG Library (CC BY-NC-SA 4.0)
//= [img:images/ecg-07.jpg] ECG 12 dérivations : quel est le diagnostic ?
[img:images/ecg-07.jpg] Quel est le diagnostic sur cet ECG 12 dérivations ? :: Flutter atrial à conduction 2/1\nActivité atriale régulière en « dents de scie » en DII, DIII, aVF\n2 ondes atriales pour 1 QRS → fréquence ventriculaire ≈ 150/min\nPiège : une tachycardie régulière à 150/min doit faire chercher un flutter\nSource : LITFL ECG Library (CC BY-NC-SA 4.0)
//= [img:images/ecg-03.jpg] Bande de rythme, le patient a un pouls : quel est le diagnostic ?
[img:images/ecg-03.jpg] Le patient a un pouls : quel est le diagnostic sur cette bande de rythme ? :: Tachycardie ventriculaire (TV) monomorphe\nComplexes larges, rapides, de forme identique\nTracé organisé : différent d'une fibrillation ventriculaire\nPas d'aspect tournant : différent d'une torsade de pointes\nUne TV peut exister avec ou sans pouls (sans pouls = arrêt cardiaque)\nSource : LITFL ECG Library (CC BY-NC-SA 4.0)
//= [img:images/ecg-09.jpg] Bande de rythme chez un patient ayant un QT long entre les accès : quel est le diagnostic ?
[img:images/ecg-09.jpg] Chez ce patient qui a un QT long entre les accès, quel est le diagnostic sur cette bande de rythme ? :: Torsade de pointes\nTachycardie ventriculaire polymorphe : l'amplitude et la polarité des complexes changent, ils « tournent » autour de la ligne de base\nTerrain : QT long (médicaments, hypokaliémie, hypomagnésémie)\nTraitement : sulfate de magnésium, corriger la kaliémie, arrêter les médicaments allongeant le QT\nSource : LITFL ECG Library (CC BY-NC-SA 4.0)
//= [img:images/ecg-10.jpg] Bande de rythme, patient inconscient et sans pouls : quel est le diagnostic ?
[img:images/ecg-10.jpg] Le patient est inconscient et sans pouls : quel est le diagnostic sur cette bande de rythme ? :: Fibrillation ventriculaire (FV) = arrêt cardiaque\nOscillations irrégulières, sans QRS organisés\nConduite : massage cardiaque, défibrillation immédiate, adrénaline selon l'algorithme\nActivité électrique organisée sans pouls : activité électrique sans pouls (dissociation électromécanique), rythme non choquable\nSource : LITFL ECG Library (CC BY-NC-SA 4.0)
//= [img:images/ecg-04.jpg] ECG 12 dérivations dans un contexte de douleur thoracique aiguë : quel est le diagnostic ?
[img:images/ecg-04.jpg] Chez ce patient qui a une douleur thoracique aiguë, quel est le diagnostic sur cet ECG 12 dérivations ? :: Syndrome coronarien aigu avec sus-décalage du ST (SCA ST+), territoire inférieur\nSus-décalage du ST en DII, DIII, aVF\nSous-décalage en miroir en aVL\nUrgence : appel du médecin, filière de reperfusion\nSource : LITFL ECG Library (CC BY-NC-SA 4.0)
